# 🌍 Global Superstore Power BI Dashboard

## 📊 Project Overview
This project is a Power BI dashboard built using the **Global Superstore dataset**.  
It provides interactive insights into **sales, profit, customers, regions, and product performance** to support business decision-making.

The dashboard is designed to help stakeholders quickly understand key performance indicators (KPIs) and identify trends and opportunities.

---

## 🎯 Objectives
- Analyze overall **sales and profit performance**
- Understand **regional and country-wise trends**
- Identify **top-performing products and customers**
- Compare performance across **categories and sub-categories**

---

## 📌 Key Insights Covered
- Total Sales, Profit, and Quantity
- Sales & Profit trend over time
- Region-wise and Market-wise performance
- Category and Sub-Category analysis
- Top products by sales and profit
- Customer segmentation insights

---

## 🛠 Tools & Technologies Used
- **Power BI Desktop**
- **DAX** (for calculated measures)
- **Global Superstore Dataset** (CSV/Excel)
